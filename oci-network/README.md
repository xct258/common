- IPv6 动态解析脚本见 [ipv6-ddns](../ipv6-ddns/)
- 自动配置脚本见 [debian-init](../debian-init/)

## 要点

1. **IPv6**：在 VNIC 上分配后，可以从实例元数据 `/opc/v2/vnics/` 读取全部地址，脚本可自动附加
2. **辅助 IPv4**：元数据不提供，也不会通过 DHCP 下发，必须在 OCI 控制台分配后，在系统内手工 `ip addr add`
3. **公网出口**：辅助 IP 只有绑定了保留公网 IP 才有独立出口，否则和主 IP 共用 NAT 网关
4. **CIDR**：系统内配置的掩码必须与子网一致（如 `10.0.0.0/24`）
5. 子网间访问还受安全列表 / NACL 限制，配好地址不代表其他子网一定可达
